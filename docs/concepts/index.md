# 仕組み

Rakka の内部がどう動いているかの説明です。使うだけなら [はじめに](../getting-started.html) で足りますが、性能や障害時の挙動を考えるときに役立ちます。

```
 BankAccount.new(id)          ハンドル（Ractorなし）
        │ command
        ▼
┌──────────────────────────────────────────────┐
│ ActorSystem   ルーティング（ホーム + 移動表）     │
└───────┬──────────────────────┬───────────────┘
        ▼                      ▼
┌────────────────┐     ┌────────────────┐
│ Shard (Ractor) │     │ Shard (Ractor) │  … コア数ぶん（Supervisorが監視）
│ アクターごとの   │     │                │
│ メールボックスと │     │                │
│ 状態           │     │                │
│ Journal        │     │ Journal        │
└───┬────────┬───┘     └───┬────────┬───┘
    │        │ append(expected_version)
    │        ▼             │        ▼
    │   ┌──────────────────────────────┐
    │   │ EventStore (PostgreSQL等)    │
    │   └──────────────────────────────┘
    ▼ publish              ▼
┌─────────────────┐     ┌──────────────────────┐
│ EventPublisher  │────▶│  EventBus            │
│   (Port)        │     │  (メインのスレッド)    │
└─────────────────┘     └──────────────────────┘
```
