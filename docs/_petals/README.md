# 花びら（three.js）

トップページで舞って積もる花びらのソース。three.js のうち使う部品だけを esbuild でまとめ、`../assets/js/petals.js` に書き出す（GitHub Pages ではビルドしないので、書き出したファイルもコミットする）。

```bash
cd docs/_petals
npm install
npm run build
```

- 読み込みは `_layouts/landing.html` の小さなスクリプトが行う。動きを減らす設定のときと WebGL が使えないときは読み込まず、ヒーローの静止した SVG の花びらが残る
- 花びらの形は `shape.py` が作り、`petals.js`（立体）と `_layouts/landing.html`（正面から見た SVG）の両方に書き込む。形を変えたら `python3 shape.py && npm run build`
- 輪郭は Ruby のロゴに寄せ（上辺はほぼ平ら、両側は真っすぐ先端へ。横に広い）、上辺の中央に桜の花びらの浅い切れ込みを入れる。ロゴそのものは写していない。薄い一枚で縁が後ろへ反り、根元の深い赤から先端の明るい赤へ色が移る。舞うと花びらのように翻る
- 動きは「生まれた時刻と乱数から決まる値（イベント）」と経過時間だけで決まる純粋な関数（`place`）。積もる位置も散った順番だけで決まるので、巻き戻して再生すると同じ場所に積もり直す
- フッターの一言を押すと、イベントを最初から再生して山を作り直す: 全部が舞い上がって巻き戻り、最初の一枚から早送りで散り直して、最後は等速で今に追いつく。全員の時間を同じ倍率で速めるので、順番も間隔も元のまま（一斉には降らない）。速さの上限は50倍で、それより速いと落ちる途中が見えず、下端に突然現れたように見える
